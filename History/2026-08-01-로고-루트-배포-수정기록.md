# 2026-08-01 로고 루트 배포 수정 기록

## 문제

`assets` 하위 경로를 예외 처리해도 Vercel 배포 제외 규칙에서 로고 이미지가 포함되지 않아 공개 사이트에서 404가 발생했습니다.

## 수정

- 공개용 로고 파일을 프로젝트 루트에 `2026-08-01-bigforest-logo.png`로 추가했습니다.
- 랜딩페이지 헤더 로고 경로를 루트 파일로 변경했습니다.
- Vercel 배포 허용 목록은 랜딩페이지, 루트 로고, `vercel.json`으로 유지했습니다.

## 검증

재배포 후 공개 도메인에서 루트 로고 URL의 HTTP 응답과 페이지 렌더링을 확인합니다.
