# 2026-08-02 상담폼 분리 컬럼 배포 기록

## 전제

Supabase `consultations` 테이블에 `business`, `region`, `consultation_method`, `interest_area` 컬럼이 생성된 것을 확인했습니다.

## 변경

랜딩페이지 상담 폼은 기존 호환용 `place`, `services` 저장을 유지하면서, 아래 값을 별도 컬럼에도 저장합니다.

- 업종 → `business`
- 지역 → `region`
- 상담 희망 방식 → `consultation_method`
- 관심 있는 영역 → `interest_area`

## 검증 범위

브라우저에서 제출 전송 payload에 4개 분리 컬럼이 포함되는지 확인한 뒤 Vercel 프로덕션에 배포합니다. 실제 테스트 신청은 고객 데이터베이스에 새 행을 생성하므로 생성하지 않습니다.
